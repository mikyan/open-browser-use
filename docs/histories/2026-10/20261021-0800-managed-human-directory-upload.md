# 人工接管支持目录上传

用户要求持续完善 Browser Use，并再次要求新包。此轮完成查看器目录上传，
随后从包含本功能的干净提交制作预览；整体能力对齐仍在进行，不创建 PR。

查看器沿原本地目录选择保留中文层级、不同子目录中的同名文件和空文件。
原网页节点决定 directory 模式，与 multiple 分开；新 v2 状态强制明确
模式，主机/扩展配套升级，并继续接受 v1 普通文件。严格验证单一根、路径
段、大小写别名和文件/目录冲突，Go 仅在自有临时树保留相对路径；不传用户
绝对路径。限额仍为每次 16 文件、单文件 32 MiB、总计 64 MiB。

目录完成要求原 native ACK、可信 input 和实际清理，普通 ACK 不能替代
枚举完成。修复异步最终准入前已被 End 撤权、却误记为已发送而无限等待的
问题：只有最终准入通过后、native 调用前才标记发送。原两项红测保存，
修复后六文件 414 项通过；已经发出且结果未知仍保留原等待义务。
UI/Go 交叉验证修复 dotless-i 保留名规则差异，36 项对照一致。

原目录失败基线保留：真实 Opening 和三次指针输入 ACK 已记录，两次 End
均 BACKEND_UNAVAILABLE。后读 FileList 未发生，不能推断它保持不变；原
退出 1 不改写，Stop 和 27 个原进程清理有独立证据。

冻结构建的完整 Go test/vet、3,326 项 Node 检查通过，其中 UI 276 项；
绑定 471 份生产输入、80 份扩展。正式目录与普通文件回归各四场实际退出
0。目录 root multiple=true、跨站 OOPIF multiple=false 均完成五文件
40,060 字节，原可信 input 先于提交 ACK；取消保持 FileList，End/Resume
与新 SDK claim 后唯一业务 POST。传输中 End/导航无提交，未提交树删除。

独立事件/业务核验分别 1,380/1,299 项，来源/生命周期核验 102/97 项均
通过，原 Stop、进程和资源清理一致。根代理确认两张选择卡截图可读。
导航以查看器收到原撤权状态为停止续传边界，native 事件传播期间仍存在
旧暂存 chunk。保留树由离散哈希和后续 POST 证明，不扩展为持续监测。

主要修改涉及扩展目录注册表和人工选择器、共享协议、Go 暂存/控制器、
查看器以及目录与普通流程验收脚本；架构、前端、参考、质量、计划和发布
文档同步。空子目录不上传；系统目录框焦点、普通公司 Edge、真实 SSO/MFA
及完整 P01–P15 仍开放。新包的构建、审计和发布结果另记交付记录。
