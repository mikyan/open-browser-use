The user requested continued Browser Use development while ordinary Edge
manual authorization is unavailable, retaining visible AI cursor, click and
element feedback without OS pointer interference. Work remains on the existing
upstream-derived project and user fork, with no PR or Pi-specific adapter.

frames. The runtime carries private original-handle and frame/session evidence
through its existing input path, projects the native border into root viewport
coordinates, and sends feedback to the exact root document. Optional geometry
does not block input; its pending native read is tracked until the original
Promise settles, and explicit lifecycle cleanup joins that actual settlement.
Raw coordinate feedback retains its existing root hit-test behavior.

Accepted press/release feedback keeps its order, including click rings. Native
command identity is captured before sending; old ACKs, late geometry, retired
renderers and lower same-turn cursor sequences cannot replace newer accepted
feedback. Cached state cannot restore invalidated geometry. Legacy standalone
observer timing and native command results remain compatible.

nested, scaled and rotated layouts. Old production preserves all six original
operations but draws six incorrect ancestor outlines. The first candidate fixes
those outlines but loses a nested click ring; that failure and its unchanged
oracle are retained. Final focused acceptance passes 2/2, related acceptance
17/17, both actual exit 0. Six original native PNGs, six unique trusted POSTs
totaling 14,185 bytes, thirteen documents and all six rings are independently
verified. End/hide and exact cleanup pass; both focused runs record zero focus
changes or activation. Node groups pass 3536 tests with one existing Windows
symlink-privilege skip and no source drift.

Complete regression passes 176/176 with actual exit 0 and the old 175 cases in
order. Independent audit verifies original frame evidence again, core keyboard,
chooser and download records, unchanged source/build identities, actual host
termination and exact process cleanup. The 536,859 ms observer interval keeps
the existing focus allowances; no new allowance is introduced.

Changes are in the pinned runtime adapters, extension feedback/backend lifecycle,
renderer, reusable browser fixture/runner and corresponding tests/documents.
