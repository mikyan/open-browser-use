# 人工接管的纯文本复制和剪切

在独立浏览器的查看器中接管页面后，Ctrl+C / Ctrl+X 会发送一次原生复制或
剪切，并将确认的纯文本交给本地浏览器剪贴板。界面分别显示等待、成功或失败。
主程序与扩展需要一起更新；旧会话不自动获得新的传输能力。

## 使用边界

- 只传纯文本，最多 64 KiB UTF-8；不传 HTML、图片或文件。
- 被控浏览器目前限定为原生版本和 revision 均匹配的 Chromium
  `156.0.8078.4` / `156.0.8078.12`。配套专用浏览器使用 `.12`；
  未核准版本在原按键发送前拒绝该操作。
- 需要本地浏览器的 ClipboardItem 和异步剪贴板写入能力。同步准备失败不会
  发送剪切。异步写入失败时，若快捷键仍在队列中，查看器取消未发送输入并
  结束本次接管、释放持键；迟到回执不能重新发送。已经发出的远端剪切不能
  撤回，界面会明确提示。
- 未产生新剪贴板版本时保留本地原内容。没有纯文本格式时拒绝传输，不能把
  没有格式解释成“空文字”。版本检查针对整个被控浏览器共享剪贴板，不能
  证明某段数据来自某个页面或 origin。
- 受限网站策略不允许共享剪贴板读取，因此不启用这次传输；不会借人工接管
  绕过原策略。普通扩展模式的既有 SDK 剪贴板接口保持原契约。

## 输入与清理

一次传输绑定原 lease、generation、sequence 和实际原生按键回执。只接纳
准确的 Ctrl 或 Meta 加 C/X，重复按下不会再复制或剪切。实际按键已确认后，
读取失败、超时或取消仍保留其回执，不能重发剪切。

浏览器版本由主程序在原 Browser 根连接上实际查询，随同一已认证的 worker /
port 通道传入，并在原租约内冻结；离屏扩展接口不支持该查询，不能替代原根
连接，也不能使用 navigator 的 UA 字符串。远端先保留不读取旧正文的
ClipboardItem，再执行原按键。未改变版本时返回
unchanged；改变后读取新纯文本并在交付前再次检查版本。原按键确认后的读取
观察期为三秒，超时停止发布，但实际尚未结束的工作仍参与清理。

结束接管、换页、失焦或断线会撤销尚未交付的文字。原持键先释放，再等待实际
剪贴板工作结束。本地浏览器已经接收的数据不能撤回，界面会保留真实写入状态，
直到该写入完成。整个流程不重放原按键，也不通过删除选区补偿剪切。
