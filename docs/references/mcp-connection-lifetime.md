# MCP 连接生命周期

`obu mcp` 的一个stdio服务实例始终使用首次选中的实际浏览器连接。
`initialize`、协议ping和列出工具不需要浏览器在线；第一次有效浏览器工具
调用按 `--socket`、`--browser`、`--profile` 或默认发现规则连接。首次
发现失败时没有绑定，之后明确提交的请求可再次发现。连接一旦建立，就
在控制协商和业务请求前固定，工具报错或超时不会改选另一个浏览器。

这覆盖 `info`、浏览器ping、普通工具、通用 `call`、复合行动脚本和
`begin_turn`，也覆盖当前tab、turn和epoch的后续使用。绑定的是实际
本地连接，不是可替换的socket路径、profile名称或可复制的extension UUID。
初次匹配仍沿用现有发现规则：无selector优先active记录，selector按
候选顺序选择匹配项；本片没有增加多匹配选择界面或全局身份认证。

## 超时、通知与断线

一个持续运行的reader读取有界原生帧。每个请求使用此连接内唯一的wire
ID，只保留当前请求的一份响应；未对外提供的通知和过期请求的回复被
消费后丢弃。因此空闲MCP不会因未读取heartbeat而积压原生host消息。
响应结构必须符合JSON-RPC 2.0，`result`和`error`恰有一个；坏帧终止连接。
合法浏览器业务错误保留连接，并原样作为工具错误返回。

排队、初次发现、控制协商和操作共享原提交期限。候选探测及其元数据读取
使用剩余发现预算，不为下一个候选重新获得整段超时。过期或本地校验失败
的请求不发送业务命令，也不关闭健康连接。
同步目录与profile文件读取本身不能被socket deadline抢断；此限制不代表
文件系统卡住时仍能保证硬性按时返回。

完整发送后等待响应超时，不能判定浏览器操作是否已经发生。服务不重放
该请求、不采用迟到结果，也不自动更新控制epoch或当前tab。reader继续
保留帧边界，后续响应不会与旧请求串线；可在同条健康连接上显式调用
`begin_turn` 读取控制状态并开始新轮次。工具期限不会重设真实连接的
读取期限，半帧迟到仍由同一个reader读完。

EOF、无效帧、写入失败或写入超时会关闭绑定，后续工具返回
`OBU_MCP_BROWSER_DISCONNECTED`，包括 `begin_turn`。服务不会通过active
记录、其他profile或原路径的新进程重新连接；需要重启MCP服务，重新
选择浏览器和开始工作。重启服务不重放旧操作，也不自动领取旧数字tab ID。
stdio服务结束或输出失败时关闭连接并等待reader退出。

## 验证边界

确定性测试使用真实本地transport与MCP stdio，覆盖active/profile/socket
选择、复合动作、同路径同UUID替换、迟到header/body、未知操作的结束ACK、
显式同连接恢复、闲置通知、写超时、坏响应、连接关闭及stdio清理。A/B
测试故意使用相同tab数字和epoch，依据各自实际请求账本确认没有跨实例发送。
真实host relay另验证通知流，控制器本身不代替真实网页任务验收。

本地运行环境没有启用CGO的竞态检测工具链，不能声称 `go test -race`
通过。

Windows Chromium 156 的真实浏览器专项 `run-ykbo3D` 两项通过、终端exit0。
同一MCP进程跨真实host退出保持存活，原操作、begin-turn和新会话开始后的
旧操作均返回连接失效。新MCP进程显式开始新轮次，网页只产生before/fresh
两笔可信点击POST，两页及其debugger target均回收；两个MCP正常退出。
独立审计核对原始stdio行、HTTP字节及制品身份，5999ms连续焦点账本
零事件、零豁免。随后默认 `run-k5giEj` 原104项103通过/1失败、terminal1；
唯一失败是JS动态跨源frame下载的原10秒等待超时，没有文件端点GET或
原生下载事件。其余四入口同类下载及全部MCP研究任务通过；尚无证据
把该失败归因于连接绑定，整体回归仍按失败记录。
独立失败审计确认原104项及制品身份，209160ms同一observer仍只有原有
六次auxiliary窗口创建激活和四次明确popup focus，root初末normal且focused。
没有新增焦点豁免；启动和退出不在此记录范围内。
该脚手架仍使用声明的loopback Native Port adapter，覆盖同浏览器/扩展的
host重启，不替代双浏览器实例或OS原生connectNative注册验收。

本片仅改变MCP服务连接生命周期及发现期限。单次CLI命令仍按每次启动的
选择参数连接，三个SDK的公开连接接口保持原样；不宣称所有SDK的重连
策略或所有平台的浏览器生命周期已由这些测试覆盖。
