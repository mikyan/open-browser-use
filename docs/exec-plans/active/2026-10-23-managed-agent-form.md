  重名字段分组、保护账单值、依赖选项、Unicode/End、选择/勾选与 shadow 输入。

  当前 generation 的偏好保存，再提交唯一申请，读原 receipt 并保留交付页。
- 两轮请求值不同，同轮双方值相同。固定首次顺序 OBU1、Codex1、Codex2、OBU2；
  四个不同 task key，不删除首次失败、不换 key 补跑成成功。

  Codex 使用当次正式 CUA/IAB。独立 solver 只得到自身公开任务和接口资料。
  不读 fixture 实现、私有账本、对方结果，不用宿主 CDP/直接 HTTP/脚本修改业务。
- 准备180秒、业务900秒、清理60秒；首次非准备调用之前记实际起点，封存原调用。
  终态保持原七字段，额外错误另存，记录问题不通过重写原件修正。
