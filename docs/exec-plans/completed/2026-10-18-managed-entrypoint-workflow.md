published as `preview-20261018-853ea92`, with independent package and download

workflow through JS, Python, Go, CLI and MCP using the formal managed supervisor.

Use the released Windows EXE and extension, pinned CfT 156.0.8078.12, dedicated

deferred at the user's request. Do not create a PR or publish another package:

## Evidence rules

The runner records API receipts, exact managed selection, original process
creation/exit observations, unrounded lifecycle JSON, fixture requests, file bytes
and complete helper shutdown. A headless browser is not by itself proof that
foreground never changed. Foreground PID matches are candidates, not process
incarnation or input causation proof. Any observation gap or failure stays visible.
The workflow is deterministic acceptance, not a model/solver or speed comparison.
