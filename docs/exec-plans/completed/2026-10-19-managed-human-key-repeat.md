## 契约与范围

- 原查看器收到的重复 keydown 不再被持键集合直接吞掉；仅传递真实事件，
  不用定时器生成重复，不重试输入，不插入假的松键/按键。
- 原 native human lease 广告可选 keyRepeatVersion=1，整个租约固定；省略
  保留旧版本行为，只读查看不得广告。Go 与 UI 均验证原租约能力。
- 可选 input.repeat 仅接纳 true 且仅用于 key/down，要求原 code 和虚拟键码
  已由该代次的原 down ACK 建立持键。每次 repeat 独立序号、原生 ACK；
  本次 key/修饰键可反映实际变化，清理保持原 held identity。
- 原生重复 down 使用 autoRepeat=true；保留 Enter 的字符阶段及网页取消。
  End、导航、失焦及错误取消未发送队列，等待原在途调用并释放一次原持键。
- 普通可打印文字继续沿原文字提交路径；不读取系统剪贴板，不动个人浏览器。
